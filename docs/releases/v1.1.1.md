# VarmanWAF v1.1.1 - Fleet topology, opaque panels

**Release date:** 2026-10-16 **Images:** `sovichetra/varmanwaf:1.1.1`,
`sovichetra/varmanwaf:latest` **Tag:** `v1.1.1`

Two fixes on top of v1.1.0, from field review: the in-place edit panel is
fully opaque, and the global topology page is now a **fleet view** - every
site, every agent and the control plane in one place, instead of a site
selector showing one site at a time.

## What this round brings

- **Fleet topology** (`/topology`): the control plane, every registered agent
  (edge node) and every site in one graph. The control plane links to each
  agent and each site (it pushes their configuration); recorded agent-to-site
  bindings appear as extra links. Click a node for its details - a site node
  opens that site's full topology, an agent node opens the Agents page.
  Placeholders state "no agents registered" / "no sites yet" rather than
  rendering an empty canvas.
- **Honest by construction**: in all-in-one deployments the platform records
  no per-site agent binding, so no "no agent" warning is invented - the
  binding chip only appears when a binding actually exists, and the page
  explains it.
- **Opaque edit panel**: the panel (and every topology node) used a theme
  class that does not exist (`bg-bg-elevated`), so the graph showed through
  the editor. The correct token (`bg-elevated`) is applied - the panel and
  nodes are now solid in both light and dark themes.
- **Navigation**: the site view gained a "Fleet view" button and the fleet
  view an "Agents" button, so the two levels are one click apart.
