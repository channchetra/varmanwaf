# VarmanWAF v0.23.0 — upstream sync round 2b (control plane + notify subsystem)

**Release date:** 2026-10-13 · **Images:** `sovichetra/varmanwaf:0.23.0`,
`sovichetra/varmanwaf:latest` · **Tag:** `v0.23.0`

The full control-plane port from PingWAF v0.25.10 is in: new APIs, the
notification subsystem, configuration versioning, and the engine's
managed-rule monitors. This closes batch 2 of the upstream sync plan.

## What this round brings

- **New REST APIs** (all routed and tested): `users` (account management),
  `notifications` (channels + events), `cache_settings` (deployment-wide
  cache ceilings), `site_failover` (per-site disconnected behaviour),
  `config_versions` (list/inspect recorded configuration versions),
  `login_security` (anomaly settings + history), `rate_limit` (auth rate
  limiting) and `ai_rate_limit`.
- **Notification subsystem** (`notify/`): encrypted channel secrets
  (AES-256-GCM via `ring`), e-mail (SMTP via `lettre`), webhooks (signed),
  certificate-expiry alerts, login-anomaly alerts (GeoIP via `maxminddb`),
  and control-plane self-monitoring (CPU/memory/disk via `sysinfo`), with a
  reload loop so channel edits apply without a restart.
- **Configuration versioning** (`config_history`): every config push records
  a snapshot (deduped by hash, off the request path), which the console and
  the `varman config` CLI can list and roll back.
- **gRPC config delivery rework**: per-agent site visibility (bound agents vs
  unbound agents of a key's owner), actor attribution on pushes, and loud
  warnings when a push reaches no agent (previously silent).
- **Engine managed-rule monitors**: per-rule monitor downgrades for managed
  *and* custom rules (`WafEngineConfig.monitor_managed_rules` /
  `monitor_custom_rules`), the managed-rule catalogue
  (`managed_rule_catalogue` + `MANAGED_RULE_IDS`) that the WAF settings API
  now exposes, and gRPC mapping of the new per-site WAF posture fields
  (`waf_enabled`, `mode`, `paranoia_level`, `monitor_managed_rules`) beside
  VarmanWAF's engine mode, virtual patches and OpenAPI spec.
- **Control-plane startup**: gRPC TLS (self-signed fallback, configured
  certificate), JWT-secret pinning, the notify/self-monitor/reload services,
  and the `pingwaf config`-style CLI surface (rebranded).
- **Schema groundwork** (from 2b-1) is now consumed: the new models feed the
  APIs above.
