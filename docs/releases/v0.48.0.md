# VarmanWAF v0.48.0 - Navigation consolidation: one identity per feature

**Release date:** 2026-10-15 **Images:** `sovichetra/varmanwaf:0.48.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.48.0`

The sidebar had grown to 20 flat items, mixing global and site-scoped
entries, with two surfaces owning the same feature. This round is the
item-by-item study and the consolidation that came out of it - recorded in
[`docs/navigation-ia.md`](../navigation-ia.md).

## What this round brings

- **Alerts and Notifications merged** into one page - **Alerts &
  notifications** (`/alerts`): a sticky section nav over **Rules**,
  **Silences**, **Channels**, **Delivery** (thresholds + per-event
  toggles), **Login security** and **History**. The old "Recent
  notifications" list was the smaller duplicate and is gone; the paged,
  filterable history replaced it. `/notifications` redirects to `/alerts`,
  so old links keep working.
- **Grouped navigation, one scope per group**:
  - **Protection** - Policies, CRS rules, Alerts & notifications,
    IP lists, Blocked IPs
  - **Traffic & logs** - Traffic, Logs, Reports
  - **Fleet** - Agents, SSL/TLS, Config history
  - **Tools** - AI Assistant, Request lifecycle
  - **This site** (contextual) - appears only inside a site: Web
    protection, Rate limiting, Bot protection, Access control, Origin,
    Caching, SSL/TLS, Traffic
  - Dashboard, Sites and Settings stay as leaves.
- **Renames to one identity per concept**: "IP Groups" -> **IP lists**,
  "IP Blacklist" -> **Blocked IPs**, "Alerts" -> **Alerts &
  notifications**.
- **Deliberately not merged** (recorded with reasons in the doc): Policies
  vs Config history (policy revisions vs configuration snapshots), IP
  lists vs Blocked IPs (static lists vs dynamic blocks), Traffic vs Logs
  (aggregates vs records), the global SSL/TLS page vs the site tab.
- The sidebar drops from 20 flat lines to ~7 collapsed groups; expanding
  a group reveals only its own scope.

## Verification at release

- `npx tsc -b` and `npx vite build` clean; 20/20 web unit tests; eslint
  clean (2 pre-existing router warnings); bundle markers for every group
  label, both renames, the merged page's section labels and the contextual
  section.
- Live E2E (navigation script): version and health on the deployed build;
  the marker set present in the served bundle; the retired `/notifications`
  path still serves the console (the redirect is client-side); the
  control-plane smoke is unchanged.
- No Rust edits: the server is byte-identical to v0.47.0.
