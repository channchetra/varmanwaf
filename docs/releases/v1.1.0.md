# VarmanWAF v1.1.0 - Routing topology, all-layers policies, docs overhaul

**Release date:** 2026-10-16 **Images:** `sovichetra/varmanwaf:1.1.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v1.1.0`

A feature-and-documentation round: the console gains a live **routing
topology** view that edits the site in place, the policies page shows every
layer at once, the config-history table is fixed, and the documentation set is
rebuilt for VarmanWAF - including a much deeper Khmer user guide and new
operator documents (sizing, HA, developer guide).

## What this round brings

- **Routing topology** (`/topology`, `/sites/:id/topology`, a site tab):
  a ReactFlow graph of the real request path - Internet → Site → Web
  Protection → Security layers → Routing → Origin pools → Targets. Every
  link is animated; security layers are grouped and each origin pool groups
  its targets; nodes are draggable with the arrangement remembered per site;
  palette items are dragged onto the canvas to add components (nothing is
  written until saved); clicking any node edits it in place (site identity,
  WAF posture, rate limits, IP rules, cache rules, basic auth, bot, geo,
  routes, pools, upstreams). Empty sections render explicit placeholders, so
  a bare site still shows the complete flow.
- **Policies show every layer at once** - no more add-one-by-one: all ten
  layer kinds render as sections, configured ones with their values and
  unconfigured ones with the same editor empty (saving creates the layer).
- **Config history table fixed** - a real Actions column, controlled column
  widths (the table gained a `fixed` layout mode), no stretched blank space,
  and Detail/Rollback buttons with icons (rollback in warning colour).
- **Console fixes** - the dev-server proxy now targets the console's TLS
  endpoint (the HTTP target caused cross-origin redirects that dropped the
  auth header), and the WAF settings types match what the API actually
  accepts (`waf_enabled`, `mode`, `paranoia_level`).
- **Documentation rebuilt for VarmanWAF**: `architecture.md` rewritten for
  the current system (the previous text still described the pre-engine
  baseline), `modules.md` rewritten as the workspace map, `api.md` gained the
  complete generated route table, and the index was cleaned up (the empty
  upstream `zh/` translations are gone). New: [`ha.md`](../../docs/ha.md)
  (edge fleets, control-plane standby, database HA, DNS and node sync),
  [`sizing.md`](../../docs/sizing.md) (requirements + the measured capacity
  and storage-growth data), [`developer-guide.md`](../../docs/developer-guide.md)
  (build/test/release workflow, where to add what, the doc rule).
- **Khmer user guide deepened**: Google Sans as the base font (with Noto Sans
  Khmer for the script), and five new chapters with worked examples -
  caching (how it works, what to cache, purge vs cache-busting), SecLang
  (what it is, virtual patches, CRS imports, worked rules), expressions and
  regex (operators, fields, full examples, testing), rate limiting and geo
  deep-dives, and the routing-topology chapter with screenshots.
