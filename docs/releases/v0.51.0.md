# VarmanWAF v0.51.0 - UI fixes: settings order, the alerts rail, the schedule row

**Release date:** 2026-10-15 **Images:** `sovichetra/varmanwaf:0.51.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.51.0`

Three reported UI defects, all frontend.

## What this round fixes

- **Settings: Dashboard users now sits next to Account.** The quick-nav
  listed the section between Account and Passkeys, but the card itself
  lived near the bottom of the page - so the menu entry scrolled past
  everything. The section now follows Account in the content, matching the
  menu exactly.
- **Alerts & notifications: the section menu is vertical, like Settings.**
  The horizontal pill row is replaced by the same sticky left rail
  (QuickNav, with scroll-spy) the Settings page uses, on wide screens; the
  pills remain as the compact fallback below `xl`. Deep links
  (`/alerts#delivery`) keep working on both.
- **Reports: the schedule row alignment.** The Window field's inline hint
  stretched its cell and pushed the row's baseline around. The fields are
  now a proper grid (2/3/6 columns by width) with a shared baseline, no
  inline hints; the window and schedule explanations sit below the grid as
  captions.

## Verification at release

- `npx tsc -b`, `npx vite build`, eslint and the 20 web unit tests clean.
- Live E2E (ui-fixes script): the three touched routes serve the console;
  the endpoints behind them answer; markers present.
