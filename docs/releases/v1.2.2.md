# VarmanWAF v1.2.2 — Google Sans console and refreshed docs

**Release date:** 2026-10-26
**Images:** `sovichetra/varmanwaf:1.2.2`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.2.2`

Patch release for the shared type system and the public documentation surface.

## What changed

- The React console now uses **Google Sans** for the interface and **JetBrains
  Mono** for IPs, expressions, logs and measurements. The existing system stack
  remains the fallback if the web fonts cannot load.
- The public docs now use the console's graphite/Signal Ember palette, Google
  Sans for text and labels, blue for links/focus, and JetBrains Mono for code.
- The docs screenshot set was audited and the six remaining non-desktop usage
  captures were replaced with 1600×900 console images.
- No API, database, migration or configuration change.

## Verification

- `web`: production build passes; console verified at 1920/1600/1440/1280/1024
  with Google Sans and JetBrains Mono, 0 errors and 0 horizontal overflow.
- Docs: 38 pages, 0 failures; 86 rendered images loaded with 0 failures
  (minimum 1366×768); 0 contrast failures in light and dark.
- Image smoke test: `/healthz` 200, `/api/v1/version` reports `1.2.2`, and the
  embedded frontend serves the Google Sans stylesheet.

## Upgrade

```bash
docker compose pull varman
docker compose up -d --force-recreate varman
curl -sk https://localhost:9080/api/v1/version   # -> 1.2.2
```

No migration and no configuration change. Roll back with the `1.2.1` tag.
