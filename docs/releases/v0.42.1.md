# VarmanWAF v0.42.1 - Style: the workspace is rustfmt-canonical at last

**Release date:** 2026-10-14 **Images:** `sovichetra/varmanwaf:0.42.1`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.42.1`

Formatting-only round: **no behaviour changes**. The tree carried a drift
against the current stable rustfmt (it was written before style edition
2024 landed), so `cargo fmt --all -- --check` - a command the README lists
as part of the gate - failed in the local container, and the GitHub
workflow's fmt step (when Actions still ran) would have been the first red
check.

## What changed

- `cargo fmt --all` with the container's stable rustfmt (1.9.0, style
  edition 2024): **27 files, +558/-381 lines** of canonical rewrapping -
  multi-line signatures and chains that fit the 80-column budget collapse
  to one line, imports take the 2024 ordering where it differed. The
  engine, plugin, cache and control-plane files among them were already
  covered by their test suites.
- The raw container diff shows 646 files because rustfmt rewrites line
  endings in the worktree: 619 of those carry **no content change** - git
  normalises CRLF/LF on commit, so the commit is exactly the 27 files.

## Verification at release

- `cargo fmt --all -- --check`: **exit 0** (the first time it passes on
  this repository).
- `cargo test --workspace --features full`: **1609 tests passed**, exit 0.
- `cargo clippy --all-targets --features full -- -D warnings`: clean.
- Deployed smoke on the rebuilt image: version `0.42.1`, `healthz`, and
  control-plane reads (`/blocked-ips`, site WAF settings,
  `/config-versions`) all answered. The data-plane probes were run
  **before and after** the swap and returned the same decisions: benign
  `GET /` 200, XSS query 403, XSS body 403, path traversal 403. (The
  attack probes arm the edge's auto-block for the probe IP, exactly as
  designed - the benign probe was re-run after lifting the block via
  `POST /sites/{id}/blocked-ips/unblock` and returned 200 again, which
  also re-verified the blocked-IP surface on the new build.)

## Next

  stay manual, exactly as the README documents.
