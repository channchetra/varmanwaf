# VarmanWAF v1.2.9 — origin Test button fits the pool card

**Release date:** 2026-10-27
**Images:** `sovichetra/varmanwaf:1.2.9`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.2.9`

Layout patch for the v1.2.8 origin health-check feature.

## The bug

The new **Test now** button sat in the pool card header next to Edit and
Delete. On a narrower window the header action row ran out of room and the
button was clipped at the card edge.

## The fix

- **Test now** moved to the pool card footer, next to **Add node**. It has room
  at every width, remains available to read-only users, and keeps its loading
  state while a probe runs.
- The pool header keeps only the Edit and Delete actions.
- No change to the probe API, health-check settings or stored status.

## Verification

- `npm run build` — console bundle builds.
- Browser check at 800 px: the pool footer shows Add node and Test now without
  clipping; the result dialog still reports status, latency and the node
  health badge.

v1.2.9 includes everything in v1.2.8 (per-pool health-check settings and the
origin reachability probe) and the Renew button wrapping fix.

## Upgrade

```bash
docker compose pull varman
docker compose up -d --force-recreate varman
curl -sk https://localhost:9080/api/v1/version   # -> 1.2.9
```

No migration and no configuration change.
