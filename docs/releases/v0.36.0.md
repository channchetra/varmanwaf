# VarmanWAF v0.36.0 - The box language, everywhere

**Release date:** 2026-10-14 **Images:** `sovichetra/varmanwaf:0.36.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.36.0`

The console now follows one consistent visual language on every page,
modelled on the studied settings panels: **explain before asking for
input**, box every section, and use the product's brand colour for
emphasis.

## What this round brings

- **Two shared primitives**
  - `Callout` - the console's only message box: icon, title, body, six
    tones (`brand` / `info` / `warning` / `danger` / `success` /
    `neutral`). Brand tone is the default for page overviews.
  - `StatGrid` - label/value tiles for summaries (replacing ad-hoc grids).
- **Overview boxes everywhere**: Dashboard, Sites, Policies, CRS rulesets,
  Alerts, IP lists, Logs, Agents, Settings, Bot Protection, Rate limiting,
  Access control, WAF rules, CC protection and Engine posture (Grading)
  each open with a brand-tinted box that says what the page answers, where
  the state lives and what its honest limits are - written operationally,
  not as marketing copy.
- **Brand colour for selection and emphasis**: pill tabs' active item is
  now brand-tinted, matching the underline tabs, primary buttons and the
  overview boxes; ad-hoc blues are gone from these surfaces.
- The language is recorded in `docs/ui-language.md` (tones, placement
  rules, what a new page must ship with) so future rounds keep it.
