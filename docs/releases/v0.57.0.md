# VarmanWAF v0.57.0 - Policy tuning: one surface, learned from Tiyi

**Release date:** 2026-10-15 **Images:** `sovichetra/varmanwaf:0.57.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.57.0`

The UX round the operator asked for: the site's protection posture now reads
as one **Policy tuning** surface, laid out like Tiyi's policy-tuning view -
a summary header with state chips, a left navigation, and the sections the
operator actually tunes. Patterns only; every panel is ours.

## What this round brings

- **Policy summary header**: state chips for engine on/off, blocking mode,
  paranoia level, strict vs normal level, the managed-rule plan
  (enforce / monitor / off counts), engine mode, policy source (assigned
  policy or site settings) and the site-override flag - plus the
  target-exclusion count and package-binding count, with quick links to
  IP access, rate limits and API assets.
- **Left navigation** (the Settings/Alerts rail with scroll-spy) anchoring
  into: **Policy summary** -> **CRS protection & posture** -> **Rule
  exceptions** -> **Exclusion packages** -> **Preview and apply** ->
  **Version history** (links to config history and the policies page).
- **One tab instead of two**: the separate Policy and Exclusions tabs on
  the site's Protection page are replaced by **Policy tuning**; the
  existing panels keep their own homes and the nav anchors to them instead
  of duplicating state.
- **Legacy links keep working**: `?tab=policy` and `?tab=exclusions`
  resolve to the tuning surface, and the policy banner now links there.
- While anchoring the policy page, a pre-existing `setState`-in-effect
  pattern was replaced with the codebase's render-phase reset.

## Verification at release

- Web `tsc`, eslint and `vite build` clean; 20/20 unit tests; the tuning
  markers are present in the built bundle.
- Live E2E (tuning script): the Protection page serves, the tuning tab
  renders with the summary chips and all six nav sections, and the legacy
  `?tab=policy` / `?tab=exclusions` links resolve to it.
- No server changes: the binary is the v0.56.1 engine with the new console
  embedded.
