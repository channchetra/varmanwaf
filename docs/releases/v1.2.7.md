# VarmanWAF v1.2.7 — row actions in SSL/TLS no longer open details

**Release date:** 2026-10-27
**Images:** `sovichetra/varmanwaf:1.2.7`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.2.7`

Patch release for the per-site certificate table introduced with the v1.2.6
live log.

## The bug

The per-site **SSL/TLS** certificate table opens the certificate details
dialog when a row is clicked. Action buttons live inside that row, and their
clicks bubbled up to the row handler. Clicking **Live log**, **Renew now**,
**Set as current** or **Delete** therefore also opened the details dialog
behind (or on top of) the action.

## The fix

- The action cell stops click propagation. Row clicks still open details;
  action buttons now perform only their own action.
- This applies to the terminal button that opens the v1.2.6 live issuance log
  and to the other certificate actions.

## Verification

- `npm run build` — console bundle builds.
- Browser check: the per-site **Live log** button opens only the log dialog
  with the certificate status, transcript and pause/copy/download controls.
- The global SSL/TLS page was unaffected because its table has no row click.

## Upgrade

```bash
docker compose pull varman
docker compose up -d --force-recreate varman
curl -sk https://localhost:9080/api/v1/version   # -> 1.2.7
```

No migration and no configuration change. v1.2.7 includes everything in
v1.2.6 (the live certificate issuance log).
