# VarmanWAF v1.6.0

**Release date:** 2026-11-28
**Images:** `sovichetra/varmanwaf:1.6.0`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.6.0`

## What this release brings

v1.6.0 is the architecture release: the WAF platform is now a first-class
workspace layer instead of a set of modules inside the Pingap foundation.

- **`varman-plugin` owns the platform plugins.** WAF (engine, stream, shadow,
  external processor, custom layers, ATO), challenge, cache, rewrite and error
  pages moved out of `pingap-plugin`. The foundation crate no longer depends on
  `varman-waf`, `varman-agent` or `varman-challenge`.
- **Explicit provider ownership.** The five process-global registries
  (`UPSTREAM`, `LOCATION`, `SERVER_LOCATIONS`, `CERTIFICATE`, `PLUGIN`) and
  their compatibility constructors are gone. `ProviderSet` owns one instance of
  each per plane; assembly, config apply, observer reload, agent reload and the
  admin diagnostics all use that set.
- **Explicit plugin registration.** `pingap-plugin`, `pingap-imageoptim`,
  `varman-plugin` and the binary's stats plugin register from start-up calls,
  not from pre-main `#[ctor]` side effects.
- **Named data-plane boot phases.** The agent-hosted plane is split into
  wait, config-manager, ACME, listener, reload-watcher and management-certificate
  phases, with tests for the certificate-status vocabulary.
- **One apply engine.** The daemon and the agent-hosted plane share
  `config_apply`, its `ApplyOptions` policies and `commit_if_applied`; a failed
  rebuild can no longer become the current config.

## Security and correctness

- Admin API: segment-boundary routing, one category owner, `--admin` wins over
  a document entry named `pingap:admin`, and mutation logs carry the
  authenticated actor.
- Agent write RPCs enforce the same site visibility as their read siblings.
- MCP API keys inherit the forced first-login password gate; AI chat is
  administrator-only.
- ACME: corrupt state is diagnosed, unissued entries no longer block every
  other certificate reload, and DNS region handling is Huawei-only.
- Certificate readiness, restart hand-over, exit flush, upstream reload health
  checks and a real listening proxy now have tests.

## Compatibility

- No config syntax change. Existing TOML/HCL/KDL files load unchanged.
- The data-plane admin API keeps its routes; invalid categories now return 400
  instead of being treated as the full document.
- `VARMAN_DISABLE_ACME` is the VarmanWAF spelling; `PINGAP_DISABLE_ACME`
  remains an alias.
