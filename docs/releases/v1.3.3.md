# VarmanWAF v1.3.3 — Protection modes enforced and visible

**Release date:** 2026-10-30
**Images:** `sovichetra/varmanwaf:1.3.3`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.3.3`

> **Follow-up:** v1.3.4 fixes per-site context invalidation for Block and
> Monitor changes. Apply [v1.3.4](./v1.3.4.md).

Pause actually stops traffic, and the sites list now says what the edge is
doing.

## Why

The WAF plugin compiles one `SiteContext` per domain and caches it against the
site's **rule-bundle** hash. Pausing a site changes `sites.status`, which is
not part of that bundle. The control plane did reload the data plane, but the
cached context kept `paused = false`, so a site paused at runtime kept serving
until the process restarted. Sites already paused when the process started were
unaffected, which made the bug look intermittent.

The plugin now reads `paused` from the live rule cache on every request, so a
status change takes effect as soon as the updated bundle reaches the edge.

## Sites list

`GET /api/v1/sites` now returns `protection_mode` alongside `status`:

| Value | Meaning |
| --- | --- |
| `block` | WAF inspection is on and findings are enforced |
| `monitor` | WAF inspection is on and findings are recorded only |
| `paused` | The site answers with a 503 maintenance page |
| `off` | Inspection is disabled |
| `pending` | The site is still being provisioned |

The value is resolved with the same builder the data plane consumes, so it
covers the rule-derived fallback for sites without a `waf_settings` row and
policy-layer overrides. The sites list renders **Blocking**, **Monitoring**
and **Paused** badges, and the Protection mode control reads the same field.

## Verification

- `test_pause_applies_without_a_new_bundle_hash` flips a site to paused while
  keeping the bundle hash constant and asserts a 503 maintenance page.
- `pingap-plugin`: 203 tests passed.
- `varman-control`: 415 tests passed.
- Dashboard production build passes.
- End-to-end on production: block → attack 403, monitor → attack passes and is
  recorded, paused → all requests 503 with no origin access, resume → block
  restored.

```bash
docker compose pull varman

curl -sk https://localhost:9080/api/v1/version   # -> 1.3.3
```

No migration is required.
