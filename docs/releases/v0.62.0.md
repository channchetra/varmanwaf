# VarmanWAF v0.62.0 - The global policies page, rebuilt

**Release date:** 2026-10-15 **Images:** `sovichetra/varmanwaf:0.62.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.62.0`

The last screen still wearing the old design: the global **Policies** page
edited a policy inside a modal with a tab strip. It now opens as a proper
surface, shaped like the site's Policy tuning page.

## What this round brings

- **A detail route per policy** (`/policies/:policyId`): the list's cards
  link into it (and creating a policy lands there), replacing the editor
  modal entirely.
- **The tuning layout**: page header with a back link, a brand callout
  stating how policies apply (unassigned sites keep their own settings;
  saves bump the revision), a **summary card with state chips** (state,
  revision, assigned sites, layer count) and the history / preview actions,
  then a **left navigation** anchoring into the sections.
- **One section per layer the policy carries** - the existing layer forms
  mounted in full width instead of tabs inside a modal, each with a short
  hint saying what the layer is (posture knobs, managed-ruleset tuning,
  custom rules, per-rule overrides, virtual patches, API schema, rate
  limits, IP access, bot posture, CRS import).
- **Add a layer** section: the kinds the policy does not carry yet are
  listed; picking one mounts its form in place and saving creates the layer
  and bumps the revision.
- **History and preview** keep their dialogs, now opened from their own
  sections.

## Verification at release

- Web `tsc`, eslint (errors), `vite build` clean; 20/20 unit tests; all
  six new markers present in the built bundle.
- Live E2E (policies script): the list and a real `/policies/{id}` route
  serve the console, the policies and detail APIs answer, and the rebuilt
  surface's markers are in the deployed bundle.
- No server changes: the binary is the v0.61.1 engine with the new console
  embedded.
