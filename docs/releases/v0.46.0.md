# VarmanWAF v0.46.0 - Reports: filters, custom heading, online preview, sample-shaped layout

**Release date:** 2026-10-14 **Images:** `sovichetra/varmanwaf:0.46.0`,
`sovichetra/varmanwaf:latest` **Tag:** `v0.46.0`

The report generator gains the operator controls requested: choose the
scope (all sites or one - already there) **and filter**, **customize the
heading**, **preview the report online before downloading**, and a layout
that mirrors the report shape operators know - cover page plus numbered
sections.

## What this round brings

- **Filters** (applied to every aggregation, summary and report alike):
  - **Action**: all decisions / blocked only / monitor-only - so a report
    can state just what was refused;
  - **Filter**: substring over the client IP and the request path.
- **Custom heading + footer note** (`GET/PUT /reports/settings`, admin):
  the cover title (default "Interception report") and an optional note
  printed above the data-source note. Saved once, used by every future
  generation - scheduled reports included (next round).
- **Online preview**: a **Preview** button renders the generated report in
  a sandboxed iframe (`sandbox=""` - no scripts can run even in principle)
  with the real file name, and a **Download** action inside the dialog;
  the download is byte-identical to the preview.
- **Sample-shaped layout**: a proper **cover page** (brand, custom heading,
  range, scope, generated-at, operator; prints as its own page) followed
  by the numbered sections operators know from their existing reports:
  **1 Interception type** (counts + share bars), **2 Attack IP ranking
  TOP20** (ordered by blocked), **3 IP report TOP20** (interceptions /
  blocked / monitor-only / last seen), **4 URL report TOP20**, **5 Daily
  timeline**.
- Tests: action-filter validation, filter placeholder/value alignment for
  every combination, numbered-section presence, custom title/note escaping
  (control suite now **358**).

## Verification at release

- `cargo fmt --check`, control tests **358 passed**, clippy
  `-D warnings` clean; web `tsc`/vite clean, 20/20 unit tests, markers for
  the filters, preview and heading card.
- Live E2E (report filters script): `action=blocked` yields
  `monitored=0` and matches the unfiltered blocked count,
  `action=monitor` yields `blocked=0`, the IP/path filter selects rows and
  a no-match filter returns zero; an unknown action is rejected (400);
  the settings round-trip a custom heading and note (present in the
  generated HTML) and are restored; the report carries the numbered
  sections; a viewer account gets 403 on the settings route too.
