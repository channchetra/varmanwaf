# VarmanWAF v1.2.0 — the topology canvas, and a smaller codebase

**Release date:** 2026-10-25
**Images:** `sovichetra/varmanwaf:1.2.0`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.2.0`

This release makes the two topology views a dedicated operations surface:
the graph gets the full content area, editing docks beside it instead of
covering it, and the fleet and site flows share one visual language. It also
lands the deep-cleanup pass (41 import cycles removed, no dead code left) and
the fleet/agent scope fixes.

There is **no database migration**. Existing sites, rules, policies, logs and
agent enrolments are preserved. The only API addition is
`served_site_ids` on agent responses.

## Topology

### Space to see and edit

- `/sites/:siteId/topology` is now full-bleed: the site header and tab strip
  are hidden on that route, and the stage fills the window below the top bar.
- The side palette is a floating icon rail; the page header, callout, badges
  and hint row that used to sit above the graph are gone. Site identity,
  counts, `Back to site` and `Fleet view` float over the canvas.
- The editor is docked to the right at desktop widths (**420 px** on a site,
  **380 px** on the fleet) and the canvas shrinks instead of being covered.
  Below `xl` it is a bottom sheet capped at 70% of the canvas.
- Clicking a node re-centres it at the current zoom, so a node on the right no
  longer disappears behind the editor.
- `Fit`, `Auto layout`, `Refresh` and `Expand` live in one centred toolbar.
  `Expand` uses the Fullscreen API on the canvas and works when the browser
  permits it.

### One graph language

- Core stages use cards, sources and targets use pills, the ten security
  layers use compact rows, and layers/routing/pools use titled group frames.
- Edges are curved signal lines that draw in once; live paths keep a slow
  pulse, and the client hop keeps the TLS warning tone. Offline agents and
  paused sites do not pulse.
- Node/edge/frame motion is one authored reveal; `prefers-reduced-motion`
  removes the reveal, draw-in and pulse.
- Light and dark are both first-class. Selection is an accessible brand-ink
  border (6.07:1 light / 9.36:1 dark) instead of React Flow's default glow.

### Fleet truth

- Agent responses now include `served_site_ids`; `GET /agents?site_id=` includes
  unbound agents that serve that site.
- The fleet graph is **control plane → agent → site** only. An unbound
  all-in-one agent links to every site owned by its API-key owner and shows
  `All sites (N)`; it is only `Unassigned` when it serves nothing.

## Cleanup and fixes

- Import cycles **41 → 0**; dead code, unused exports/constants/helpers and
  placeholder pages removed; `cargo-machete` clean.
- Cache is disabled when a request plugin answers before the upstream
  exchange, removing the pingora dangling-lock assertion path.
- Default error pages and webhook hints use the VarmanWAF name/token.
- ACME retry with an empty identity returns a meaningful **400** instead of
  **500**.
- The legacy `/sites/:siteId/security/policy` link now lands on the merged
  Protection policy tab; previously it resolved to a 404.
- Topology no longer ships a minimap or the old dashed React Flow animation.

## Upgrade

```bash
docker compose pull varman
docker compose up -d --force-recreate varman
curl -sk https://localhost:9080/api/v1/version
```

No migration and no configuration change are required. Roll back with the
previous image tag; the database schema is unchanged.
