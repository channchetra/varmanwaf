# VarmanWAF v1.4.1 — Unblock my IP

**Release date:** 2026-11-02
**Images:** `sovichetra/varmanwaf:1.4.1`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.4.1`

A one-click recovery path for operators who blocked themselves while tuning a
policy.

## What changed

- The **IP Blacklist** page has an **Unblock my IP** action.
- The control plane resolves the dashboard request's **TCP peer address**
  (the same address its self-protection allowlist sees) and removes every
  dynamic block for that IP across all sites.
- An `unblock_ip` command is sent to every agent that was enforcing the
  block, and the `agent_blocked_ips` mirror rows are deleted immediately.
- The response reports the resolved IP, number of sites, agents and delivered
  commands. If the IP was not blocked, the UI says so instead of pretending
  something changed.
- The action is administrator-only. For a dashboard behind a reverse proxy,
  the peer is the proxy; use the per-row **Unblock** action for a real client
  IP in that topology.

## Verification

- Local all-in-one stack: create a site, manually block `127.0.0.1`, confirm
  the row is listed, call `POST /blocked-ips/unblock-current` from the
  container peer, confirm the row disappears and the agent receives the
  unblock command.
- `varman-control`: 420 tests passed.
- Dashboard: 47 tests passed; production build passes.

## Upgrade

```bash
docker compose pull varman
docker compose up -d --force-recreate varman
curl -sk https://localhost:9080/api/v1/version   # -> 1.4.1
```

Migration 068 from 1.4.0 still applies automatically. No new migration is
required for this release.
