# VarmanWAF v1.3.5 — Dashboard recovers from stale chunks

**Release date:** 2026-10-30
**Images:** `sovichetra/varmanwaf:1.3.5`, `sovichetra/varmanwaf:latest`
**Tag:** `v1.3.5`

## Why

After a deployment, an already-open dashboard tab still references the old
hashed lazy chunks. Navigating to a page whose chunk no longer exists raised
React Router's default developer error:

```text
Failed to fetch dynamically imported module: /assets/RewritePage-DZsN0kb5.js
```

A manual refresh fixed it, but the error screen was not acceptable.

## Fix

- Added a route-level error boundary (`RouteErrorPage`) with a branded retry
  panel.
- Chunk-load failures trigger one automatic reload, guarded by a 10-second
  `sessionStorage` timestamp so a broken deployment cannot create a reload
  loop.
- Vite's `vite:preloadError` event uses the same guarded reload.
- `index.html` was already served with `max-age=0`; hashed assets keep their
  long cache. This release handles the open-tab case that cache headers alone
  cannot cover.
- Added `web/src/lib/chunkReload.test.ts` covering Vite and webpack-style
  chunk errors.
- Fixed the sites list label mapping: `block` now renders **Blocking** and
  `monitor` renders **Monitoring** (the previous build looked up
  `status.block` / `status.monitor` and showed the short action names).

## Private documentation

Added `docs/private/attack-simulation.md`, an internal guide for testing rules
with SQLi, XSS, command injection, Log4Shell, LFI, SSRF, scanner, dotfile,
backup-file, unsafe-method and URI-length probes, plus the Block/Monitor/Paused
matrix and cleanup steps. It is not part of the public website build.

## Verification

- Dashboard production build passes.
- `vitest`: 47 tests passed.
- Manual stale-chunk path: the error element reloads once, then shows the
  retry panel if the chunk still cannot be fetched.

## Upgrade

```bash
docker compose pull varman
docker compose up -d --force-recreate varman
curl -sk https://localhost:9080/api/v1/version   # -> 1.3.5
```

No migration is required.
